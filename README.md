# Hallucination Detection via Warp Variance

This repository implements a **training-free hallucination detector** for robot video frames. Given
a query frame from a VLA policy rollout, the detector measures how inconsistently RoMaV2 dense warp
fields across clean reference frames map to that query: a clean frame is well-explained by multiple
references (low warp variance), while a hallucinated frame forces each reference to invent a
different mapping (high warp variance). That per-pixel certainty-weighted variance is calibrated
against a per-task empirical null distribution built from known-clean reference frames; the
resulting H-score in [0, 1] represents the probability that the frame is hallucinated, and
threshold `H > 1 - fpr_alpha` (default 0.95) labels it a hallucination.

---

## Quick Start

```bash
# 1. Install
pip install -e .

# 2. Build per-task empirical null distributions from clean references
python -m warp_score \
    --config warp_score/configs/default.yaml \
    calibrate

# 3. Score all query/{high,low} frames → artifacts/v9_dreamgen/summary.csv
python -m warp_score \
    --config warp_score/configs/default.yaml \
    detect

# 4. Evaluate AUROC / AP / FPR@95TPR
python -m warp_score \
    --config warp_score/configs/default.yaml \
    eval --labels labels.csv
```

Or use the root Makefile (see [Makefile targets](#makefile-targets)):

```bash
make install
make calibrate
make detect
make eval
```

## Setup

1. **Clone the repo** — you have it already.

2. **Install the package** (use the `groot` conda env on this machine):
   ```bash
   conda activate groot
   pip install -e .
   ```

3. **Set up the data directory** — `data/` is `.gitignore`d and not committed.
   The expected layout is:
   ```
   data/
     reference/<task>/*.png      # calibration refs (LOO null)
     query/high/<task>/*.png     # clean held-out queries (AUROC label=0)
     query/low/<task>/*.png      # hallucinated queries (AUROC label=1)
   ```
   On this machine the symlinks are already created. For a new machine:
   ```bash
   mkdir -p data
   ln -s /path/to/reference             data/reference
   ln -s /path/to/query                 data/query
   ln -s /path/to/cosmos_frames_raw     data/cosmos_frames_raw
   ln -s /path/to/cosmos_synthetic_data data/cosmos_synthetic_data
   # OR copy the actual directories there if you have the data locally
   ```

4. **RoMaV2** — the dense matcher. Source is bundled in `third_party/RoMaV2/`; weights
   download automatically on first run. Add it to your PYTHONPATH:
   ```bash
   # Bundled copy (preferred):
   export PYTHONPATH=$(pwd)/third_party/RoMaV2/src:$PYTHONPATH
   # Or the shared checkout on this machine:
   export PYTHONPATH=/mnt/data/sftp/data/quangpt3/gcvwm/calibration/RoMaV2/src:$PYTHONPATH
   ```

5. **Run the pipeline**:
   ```bash
   bash scripts/run_pipeline.sh
   ```

## Data Layout

```
data/
├── reference/                  # calibration references — LOO null (was image_no_bg/high)
│   ├── 0_Open_the_box/
│   │   ├── frame_0001.png
│   │   └── ...                 # up to 50 frames
│   ├── 1_Close_the_box/
│   └── ...                     # 23 task directories
└── query/
    ├── high/                   # clean held-out queries  (AUROC label=0, NEW)
    │   ├── 0_Open_the_box/
    │   └── ...                 # same 23 task directories
    └── low/                    # hallucinated queries    (AUROC label=1, was image_no_bg/low)
        ├── 0_Open_the_box/
        └── ...                 # same 23 task directories
```

- **23 tasks**, up to **50 frames** per task per split.
- Background pixels are exactly `(127, 127, 127)` (SAM3 segmentation output) — the foreground mask
  relies on this exact value.
- Task identity is `Path(frame).parent.name`; task names must match across `reference/` and
  `query/{high,low}/`.
- Generated by `dreamgen_data/` (cosmos-predict2 2B model, see [Full Pipeline](#full-pipeline)).

### 1. Generate synthetic data with DreamGen

Or from the repo root:

```bash
make dreamgen-smoke     # smoke test

```

### 2. Build weak labels CSV

```bash
python scripts/build_weak_labels.py \
    --query_high_dir data/query/high \
```


```bash

make eval
```

## Package Structure

| Module | What it does |
|---|---|
| `warp_score/config.py` | `WarpScoreConfig` dataclass — single source of truth for all hyperparameters. Load from YAML or override via CLI. |
| `warp_score/matcher.py` | `RoMaMatcher` — thin OOP wrapper around RoMaV2. Returns `(warp_HW2, cert_HW)` with background certainty zeroed. |
| `warp_score/mask.py` | `ForegroundMask` (gray-pixel exclusion) and `InteriorMask` (morphological erosion to drop boundary artifacts). |
| `warp_score/statistics.py` | `CertWeightedStatistics` — computes certainty-weighted warp mean and variance maps across a stack of references. |
| `warp_score/calibrator.py` | `EmpiricalNullCalibrator` builds per-task sorted null distributions from `data/reference/` refs (LOO); `CalibrationArtifact` handles save/load. |
| `warp_score/signals.py` | `IvarSignal` (integrated variance), `PeakSignal` (99th-percentile variance), `CertSignal` (mean certainty). Each returns a scalar p-value against the null. |
| `warp_score/fuser.py` | `StoufferFuser`, `FisherFuser`, `MaxFuser` — combine per-signal p-values into a single H-score. |
| `warp_score/detector.py` | `WarpVarianceDetector` — end-to-end: load query, run matcher against task refs, compute signals, fuse → `HallucinationResult`. |
| `warp_score/visualizer.py` | `HeatmapPlotter` — saves per-frame warp-variance overlay PNGs to `artifacts/heatmaps/`. |
| `warp_score/evaluator.py` | `Evaluator` — joins labels CSV with predictions CSV, computes AUROC / AP / FPR@95TPR, prints + saves JSON report. |
| `warp_score/cli.py` | `python -m warp_score` entrypoint; three subcommands: `calibrate`, `detect`, `eval`. |

## Config

All behaviour is controlled by a single YAML. Edit
`warp_score/configs/default.yaml` (or copy it for a new experiment):

```yaml
# Key settings

# Paths — override these or pass --ref_dir / --query_high_dir / --query_low_dir / --artifacts_dir on the CLI
reference_dir:   data/reference
query_high_dir:  data/query/high
query_low_dir:   data/query/low
artifacts_dir:   artifacts/v9_dreamgen

# RoMaV2 matching
setting:         turbo      # turbo | fast | base | precise
vis_size:        224        # resolution for matching (smaller = faster)
bidirectional:   false

# Signals + fusion
signal_names:    [ivar, peak, cert]
fuser:           stouffer   # stouffer | fisher | max
stouffer_weights:
  ivar: 2.0
  peak: 1.0
  cert: 1.0

# Decision
fpr_alpha:       0.05       # H_score > 0.95 → hallucination
```

Pass a custom config with `--config path/to/custom.yaml`. All path flags
(`--ref_dir`, `--query_high_dir`, `--query_low_dir`, `--artifacts_dir`, `--device`, `--setting`) override the YAML.

## CLI Reference

```
python -m warp_score [--config YAML] [--ref_dir DIR]
                     [--query_high_dir DIR] [--query_low_dir DIR]
                     [--artifacts_dir DIR] [--device DEVICE] [--setting SETTING]
                     {calibrate,detect,eval} ...
```

### `calibrate`

Scans `reference_dir/**/*.png`, groups frames by task (parent directory name), and runs all-pairs
RoMaV2 matching to build a per-task empirical null distribution. Saves
`artifacts_dir/calibration.npz`. No extra flags.

### `detect`

Loads calibration, scores query frames, appends rows to `artifacts_dir/summary.csv`.

| Flag | Default | Description |
|---|---|---|
| `--query PATH` | — | Score a single PNG. |
| `--query_dir DIR` | — | Score all PNGs under DIR recursively. |
| `--task NAME` | — | Score `query_high_dir/<task>` + `query_low_dir/<task>`. |
| (none of the above) | both `query_high_dir` + `query_low_dir` | Score every PNG under both query subtrees (lets a single run compute AUROC). |

### `eval`

Joins a labels CSV with the predictions CSV, prints and saves an evaluation report.

| Flag | Default | Description |
|---|---|---|
| `--labels PATH` | required | CSV with columns `frame,label` (at minimum). |
| `--pred PATH` | `artifacts_dir/summary.csv` | Predictions CSV (output of `detect`). |
| `--out PATH` | `artifacts_dir/eval_report.json` | Where to save the JSON report. |

## Hardware

Designed for a **single NVIDIA H100 80 GB**.

| Step | Approx. time |
|---|---|
| Calibrate (23 tasks × 50 refs, turbo setting) | ~4 hours |
| Detect (23 tasks × 50 queries) | ~1–2 hours |
| DreamGen full generation (2B model) | ~2–3 hours |

Set `setting: fast` in the config to reduce matching time at a small accuracy cost.
